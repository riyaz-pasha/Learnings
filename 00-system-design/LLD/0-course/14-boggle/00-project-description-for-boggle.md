# Project Description for Boggle

## Introduction

Boggle is a popular word game traditionally played on a plastic grid of lettered dice. Usually the grid is 4x4 or bigger. Players take turns finding words that can be built from the letters of sequentially adjacent dice — the same die cannot be reused within one word. Many variations of this game exist.

## Statement

Suppose you're working for a startup building web versions of traditional board games. They've decided to create a variation of Boggle, and you're on the team responsible for it. The game supports single-player mode, so your team also needs to build a computer player to play against users. The game will additionally offer multiple difficulty levels.

We need two modules to power the computer player. The first is for easy mode, where only a single word needs to be found in the Boggle grid each turn. The second is for difficult mode, where the computer player must find the maximum possible number of words in the Boggle grid from a given set of candidate words.

## Features

To implement the above functionality, we need the following features:

- **Feature #1:** For the game's easy mode, search for a single word in the Boggle grid.
- **Feature #2:** For the difficult mode, find all possible words that exist in the Boggle grid from a given list of words.

Understanding these feature requests and designing their solutions will help us implement the requested functionality into the game. In the coming lessons, we'll discuss these features and their solutions in detail, so you'll be able to apply the same patterns to other interview problems too.
