# What Did We Learn?

## What have we accomplished?

The problems we solved to implement our Cyber Security features are also among the most popular interview questions asked at top-tier companies. Now that you've seen them wrapped in a real-world scenario, you can recognize the same underlying pattern the next time it shows up in a different disguise.

Here's how each feature maps to its underlying interview pattern and matching DIY practice problem:

| Feature | Underlying pattern | Practice problem |
|---|---|---|
| Feature #1: Validate Packet Structure | Bit manipulation (header-bit counting) | [DIY: UTF-8 Validation](07-diy-utf-8-validation.md) |
| Feature #2: Verify Message Integrity | Hashing (letter-rank lookup) + linear scan | [DIY: Verifying an Alien Dictionary](08-diy-verifying-an-alien-dictionary.md) |
| Feature #3: Find Dictionary | Graph construction + topological sort (Kahn's algorithm) | [DIY: Alien Dictionary](09-diy-alien-dictionary.md) |
| Feature #4: Ways to Decode Message | Dynamic programming (recursion + memoization) | [DIY: Decode Ways](10-diy-decode-ways.md) |
| Feature #5: Eligible Candidates | Binary search + two pointers (sliding window) | [DIY: Find K Closest Elements](11-diy-find-k-closest-elements.md) |

The five DIY lessons that follow strip away the cyber security framing entirely and hand you each pattern in its bare, LeetCode-style form — good practice for recognizing these patterns even when there's no story attached.
