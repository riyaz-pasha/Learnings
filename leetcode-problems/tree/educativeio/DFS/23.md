Yes — this is the classic **“Height of Binary Tree After Subtree Removal Queries”** problem.

The key is to avoid actually deleting the subtree for every query.

## 1. First understand what the query means

Suppose we have:

```text
              1
            /   \
           2     3
          / \   / \
         4   5 6   7
            /
           8
```

Height of the original tree:

```text
1 -> 2 -> 5 -> 8
```

That's `3` edges.

Now query:

```text
remove subtree rooted at 2
```

We're removing **everything below 2**, not just node `2`:

```text
              1
                \
                 3
                / \
               6   7
```

Height becomes:

```text
1 -> 3 -> 6
```

which is `2`.

---

# The key observation

For every node `x`, imagine:

> **What would the tree's height be if the entire subtree rooted at `x` disappeared?**

We can precompute that answer for **every node**.

Then each query becomes:

```text
answer[queries[i]]
```

So instead of:

```text
For every query:
    remove subtree
    calculate height
```

we do:

```text
Precompute answer for every node
Then:
    answer[query]
```

The interesting part is figuring out how to precompute it.

---

# 2. Think about the height that survives

Consider:

```text
                    1
                  /   \
                 2     3
                / \   / \
               4   5 6   7
```

Suppose we remove subtree `2`.

```text
                    1
                      \
                       3
                      / \
                     6   7
```

The remaining height is determined by:

```text
1 -> 3 -> 6
```

So the answer for node `2` depends on the **path above 2** and the **other branches**.

This gives us an important concept:

> For a node, the answer after removing its subtree is the maximum height obtainable **outside that subtree**.

We'll call this:

```text
up[node]
```

Meaning:

```text
up[node] =
height of the remaining tree
after removing node's entire subtree
```

---

# 3. What information do we need?

We need two things.

### A. Height of every subtree

For example:

```text
              1
             / \
            2   3
           / \
          4   5
```

We calculate:

```text
height(4) = 0
height(5) = 0

height(2) = 1

height(3) = 0

height(1) = 2
```

We'll calculate this with **postorder DFS**.

---

### B. The best height coming from outside each subtree

For example:

```text
              1
             / \
            2   3
           / \
          4   5
```

For node `2`, removing its subtree leaves:

```text
        1
         \
          3
```

So:

```text
up[2] = 1
```

For node `4`, removing only `4` leaves:

```text
              1
             / \
            2   3
             \
              5
```

Longest path:

```text
1 -> 2 -> 5
```

Therefore:

```text
up[4] = 2
```

---

# 4. The crucial formula

Suppose we are currently at:

```text
            parent
           /      \
        child     sibling
```

and we're calculating the answer for `child`.

After deleting `child`'s subtree, there are two possible ways to get a tall remaining tree.

### Option 1 — Go above the parent

There may already be a tall path outside the parent's subtree.

That's:

```text
up[parent]
```

### Option 2 — Go through the sibling

Suppose:

```text
                 parent
                /      \
             child    sibling
                        |
                       ...
```

If we remove `child`, we can travel:

```text
root
 |
 ...
 |
parent
 |
sibling
 |
deepest leaf
```

If `depth[parent]` is the number of edges from root to parent, then:

```text
depth[parent] + 1 + height(sibling)
```

So:

```text
up[child] =
max(
    up[parent],
    depth[parent] + 1 + height(sibling)
)
```

That's the heart of the solution.

---

# 5. Why `depth[parent] + 1 + height(sibling)`?

Let's make it visual.

```text
                    1
                   /
                  P
                 / \
              CHILD SIBLING
                     |
                     X
```

If `CHILD` is removed, we can still go:

```text
root
 |
 ...
 |
 P
 |
 SIBLING
 |
 ...
 |
 X
```

Suppose:

```text
depth[P] = 2
height[SIBLING] = 3
```

Then:

```text
2 + 1 + 3
```

The `+1` is the edge:

```text
P -> SIBLING
```

So the surviving path has:

```text
6 edges
```

---

# 6. We need TWO DFS passes

This is the cleanest way to think about it.

## DFS #1 — Postorder

Calculate:

```text
height[node]
```

using:

```text
height(node) =
1 + max(
    height(left),
    height(right)
)
```

with leaf:

```text
height(leaf) = 0
```

---

## DFS #2 — Preorder

Calculate:

```text
up[node]
```

while carrying:

```text
depth
```

from the root.

For each child:

```text
up[child] =
max(
    up[parent],
    depth[parent] + 1 + height(sibling)
)
```

---

# 7. Complete Java implementation

Below is the version I'd recommend learning.

```java
import java.util.*;
import ds_v1.BinaryTree.TreeNode;

/**
 * ============================================================================
 * HEIGHT OF BINARY TREE AFTER SUBTREE REMOVAL QUERIES
 * ============================================================================
 *
 * Given:
 *
 *      root
 *      queries[]
 *
 * For every query x:
 *
 *      Remove the ENTIRE subtree rooted at x.
 *
 * Return the height of the remaining tree.
 *
 *
 * IMPORTANT:
 *
 * Queries are INDEPENDENT.
 *
 * That means:
 *
 *      Query 1 -> remove subtree -> calculate height
 *
 *      Then tree comes back to ORIGINAL state.
 *
 *      Query 2 -> remove subtree -> calculate height
 *
 *
 * We therefore do NOT actually modify the tree.
 *
 *
 * ============================================================================
 * EXAMPLE
 * ============================================================================
 *
 *
 *                    1
 *                  /   \
 *                 2     3
 *                / \   / \
 *               4   5 6   7
 *
 *
 * Height of original tree:
 *
 *      1 -> 2 -> 4
 *
 * = 2 edges
 *
 *
 * Query:
 *
 *      remove 2
 *
 *
 * Remaining:
 *
 *                    1
 *                      \
 *                       3
 *                      / \
 *                     6   7
 *
 *
 * Height:
 *
 *      1 -> 3 -> 6
 *
 * = 2
 *
 *
 * Query:
 *
 *      remove 3
 *
 *
 * Remaining:
 *
 *                    1
 *                   /
 *                  2
 *                 / \
 *                4   5
 *
 *
 * Height:
 *
 *      1 -> 2 -> 4
 *
 * = 2
 *
 *
 * ============================================================================
 * CORE IDEA
 * ============================================================================
 *
 * For every node x, calculate:
 *
 *      answer[x]
 *
 * where:
 *
 *      answer[x] =
 *      height of tree after removing subtree rooted at x
 *
 *
 * Then every query becomes:
 *
 *      answer[queries[i]]
 *
 * ============================================================================
 */
public class HeightAfterSubtreeRemoval {

    /*
     * ------------------------------------------------------------------------
     * height[node]
     * ------------------------------------------------------------------------
     *
     * Stores the height of the subtree rooted at node.
     *
     *
     * Example:
     *
     *             1
     *            / \
     *           2   3
     *          / \
     *         4   5
     *
     *
     * height[4] = 0
     * height[5] = 0
     * height[2] = 1
     * height[3] = 0
     * height[1] = 2
     *
     *
     * Since:
     *
     *      Node.data <= n
     *
     * we can simply use an array indexed by node value.
     */
    private static int[] height;


    /*
     * ------------------------------------------------------------------------
     * answer[node]
     * ------------------------------------------------------------------------
     *
     * answer[node] means:
     *
     *      "What is the height of the tree if the COMPLETE subtree
     *       rooted at node is removed?"
     *
     *
     * Example:
     *
     *             1
     *            / \
     *           2   3
     *          / \
     *         4   5
     *
     *
     * Remove subtree 2:
     *
     *             1
     *              \
     *               3
     *
     *
     * Therefore:
     *
     *      answer[2] = 1
     *
     *
     * Remove subtree 4:
     *
     *             1
     *            / \
     *           2   3
     *            \
     *             5
     *
     *
     * Longest path:
     *
     *      1 -> 2 -> 5
     *
     * Therefore:
     *
     *      answer[4] = 2
     */
    private static int[] answer;


    // =========================================================================
    // PUBLIC METHOD
    // =========================================================================

    /**
     * Returns the height of the tree after removing each queried subtree.
     *
     *
     * Time:
     *
     *      O(n + m)
     *
     *
     * Space:
     *
     *      O(n)
     */
    public static int[] treeQueries(
            TreeNode<Integer> root,
            int[] queries) {

        /*
         * Since:
         *
         *      1 <= node.data <= n
         *
         * and n <= 500,
         *
         * arrays are perfect for storing information by node value.
         */
        int n = 500;

        height = new int[n + 1];
        answer = new int[n + 1];


        // =====================================================================
        // FIRST DFS
        // =====================================================================
        //
        // Calculate:
        //
        //      height[node]
        //
        // for every node.
        //
        // We need subtree heights before we can calculate "up" answers.
        //
        calculateHeight(root);


        // =====================================================================
        // SECOND DFS
        // =====================================================================
        //
        // Calculate:
        //
        //      answer[node]
        //
        // for every node.
        //
        // root has no parent, so there is no "outside" subtree for root.
        //
        // We don't query root according to the problem.
        //
        calculateAnswers(root, 0, 0);


        // =====================================================================
        // ANSWER QUERIES
        // =====================================================================
        //
        // We don't modify the tree.
        //
        // We already know the answer for every possible node.
        //
        int[] result = new int[queries.length];

        for (int i = 0; i < queries.length; i++) {

            result[i] = answer[queries[i]];
        }


        return result;
    }


    // =========================================================================
    // DFS #1: CALCULATE SUBTREE HEIGHT
    // =========================================================================

    /**
     * Calculates height of every subtree.
     *
     *
     * We use POSTORDER:
     *
     *      LEFT
     *      RIGHT
     *      ROOT
     *
     *
     * Why?
     *
     * Because parent's height depends on children's heights.
     *
     *
     * Example:
     *
     *             1
     *            / \
     *           2   3
     *
     *
     * To calculate height(1), we first need:
     *
     *      height(2)
     *      height(3)
     *
     *
     * Therefore:
     *
     *      children first
     *      parent later
     */
    private static int calculateHeight(
            TreeNode<Integer> node) {

        /*
         * Empty subtree:
         *
         * height = -1
         *
         * Why -1?
         *
         * Because height is measured in EDGES.
         *
         *
         * For a leaf:
         *
         *      height(leaf) = 0
         *
         *
         * Its children are null:
         *
         *      height(null) = -1
         *
         *
         * Then:
         *
         *      height(leaf)
         *          =
         *      1 + max(-1, -1)
         *
         *          =
         *      0
         *
         *
         * This makes the formula beautifully uniform.
         */
        if (node == null) {
            return -1;
        }


        /*
         * First calculate LEFT subtree height.
         */
        int leftHeight =
                calculateHeight(node.left);


        /*
         * Then calculate RIGHT subtree height.
         */
        int rightHeight =
                calculateHeight(node.right);


        /*
         * Height of current node:
         *
         *      1 + max(leftHeight, rightHeight)
         *
         *
         * The +1 represents the edge from:
         *
         *      current node
         *
         * to:
         *
         *      child
         */
        height[node.data] =
                1 + Math.max(
                        leftHeight,
                        rightHeight
                );


        /*
         * Return this subtree's height to the parent.
         */
        return height[node.data];
    }


    // =========================================================================
    // DFS #2: CALCULATE ANSWERS
    // =========================================================================

    /**
     * Calculates answer[node] for every node.
     *
     *
     * Parameters:
     *
     *      node
     *          Current node.
     *
     *      depth
     *          Number of edges from root to current node.
     *
     *      outsideHeight
     *          Best height we can obtain without using current node's subtree.
     *
     *
     * Think of outsideHeight as:
     *
     *      "How tall can the tree already be if I completely remove
     *       the subtree I'm currently standing on?"
     *
     *
     * For every child we calculate a new outsideHeight.
     */
    private static void calculateAnswers(
            TreeNode<Integer> node,
            int depth,
            int outsideHeight) {

        if (node == null) {
            return;
        }


        /*
         * For this node:
         *
         * outsideHeight is exactly the answer.
         *
         *
         * Example:
         *
         * If removing subtree 4 leaves a longest path of length 2:
         *
         *      answer[4] = 2
         */
        answer[node.data] = outsideHeight;


        // =====================================================================
        // PROCESS LEFT CHILD
        // =====================================================================

        if (node.left != null) {

            /*
             * Suppose:
             *
             *              node
             *             /    \
             *          LEFT   RIGHT
             *
             *
             * We are calculating:
             *
             *      answer[LEFT]
             *
             *
             * Once LEFT subtree is removed, we can still use:
             *
             * 1. Anything outside node's subtree.
             *
             * 2. The RIGHT subtree.
             *
             *
             * ---------------------------------------------------------------
             * OPTION 1
             * ---------------------------------------------------------------
             *
             * The path that was already available outside node:
             *
             *      outsideHeight
             *
             *
             * ---------------------------------------------------------------
             * OPTION 2
             * ---------------------------------------------------------------
             *
             * Go from root down to node:
             *
             *      depth
             *
             * then take edge:
             *
             *      node -> RIGHT
             *
             * which contributes:
             *
             *      +1
             *
             * then travel through RIGHT subtree:
             *
             *      height[right]
             *
             *
             * Total:
             *
             *      depth + 1 + height[right]
             *
             *
             * Therefore:
             *
             *      answer[LEFT] =
             *
             *      max(
             *          outsideHeight,
             *          depth + 1 + height[RIGHT]
             *      )
             */


            /*
             * If right child doesn't exist:
             *
             *      height[right] = -1
             *
             * Therefore:
             *
             *      depth + 1 + (-1)
             *
             *      = depth
             *
             *
             * Which correctly represents the path ending at node.
             */
            int heightThroughRight =
                    depth + 1 +
                    getHeight(node.right);


            int newOutsideForLeft =
                    Math.max(
                            outsideHeight,
                            heightThroughRight
                    );


            /*
             * Move into LEFT subtree.
             *
             * New depth:
             *
             *      depth + 1
             */
            calculateAnswers(
                    node.left,
                    depth + 1,
                    newOutsideForLeft
            );
        }


        // =====================================================================
        // PROCESS RIGHT CHILD
        // =====================================================================

        if (node.right != null) {

            /*
             * Symmetric logic.
             *
             * We are calculating:
             *
             *      answer[RIGHT]
             *
             *
             * If RIGHT is removed, we can use:
             *
             * 1. outsideHeight
             *
             * 2. LEFT subtree
             *
             *
             * Path through LEFT:
             *
             *      depth
             *        +
             *      node -> LEFT
             *        +
             *      height[left]
             *
             *
             * Therefore:
             *
             *      depth + 1 + height[left]
             */
            int heightThroughLeft =
                    depth + 1 +
                    getHeight(node.left);


            int newOutsideForRight =
                    Math.max(
                            outsideHeight,
                            heightThroughLeft
                    );


            /*
             * Move into RIGHT subtree.
             */
            calculateAnswers(
                    node.right,
                    depth + 1,
                    newOutsideForRight
            );
        }
    }


    // =========================================================================
    // HELPER: HEIGHT OF NULL = -1
    // =========================================================================

    /**
     * Returns:
     *
     *      -1 for null
     *      height[node] otherwise.
     *
     *
     * This makes the formula:
     *
     *      depth + 1 + height(sibling)
     *
     * work even when sibling doesn't exist.
     */
    private static int getHeight(
            TreeNode<Integer> node) {

        if (node == null) {
            return -1;
        }

        return height[node.data];
    }


    // =========================================================================
    // TRACE
    // =========================================================================

    /*
     *
     * Let's trace the algorithm on:
     *
     *
     *                 1
     *                / \
     *               2   3
     *              / \   \
     *             4   5   6
     *
     *
     * =========================================================================
     * FIRST DFS
     * =========================================================================
     *
     * Calculate subtree heights.
     *
     *
     * Node 4:
     *
     *      height[4] = 0
     *
     * Node 5:
     *
     *      height[5] = 0
     *
     * Node 2:
     *
     *      height[2]
     *          =
     *      1 + max(0, 0)
     *
     *          = 1
     *
     *
     * Node 6:
     *
     *      height[6] = 0
     *
     *
     * Node 3:
     *
     *      height[3]
     *          =
     *      1 + max(-1, 0)
     *
     *          = 1
     *
     *
     * Node 1:
     *
     *      height[1]
     *          =
     *      1 + max(1, 1)
     *
     *          = 2
     *
     *
     * Final:
     *
     *      height[1] = 2
     *      height[2] = 1
     *      height[3] = 1
     *      height[4] = 0
     *      height[5] = 0
     *      height[6] = 0
     *
     *
     * =========================================================================
     * SECOND DFS
     * =========================================================================
     *
     *
     * Start:
     *
     *      node = 1
     *      depth = 0
     *      outsideHeight = 0
     *
     *
     * Why outsideHeight = 0?
     *
     * We don't query root.
     *
     * For root's children, the path through the other child will determine
     * the answer.
     *
     *
     * -------------------------------------------------------------------------
     * Calculate answer[2]
     * -------------------------------------------------------------------------
     *
     * Remove subtree 2.
     *
     * Remaining:
     *
     *             1
     *              \
     *               3
     *                \
     *                 6
     *
     *
     * Height = 2.
     *
     *
     * Formula:
     *
     *      answer[2]
     *      =
     *      max(
     *          outsideHeight,
     *          depth + 1 + height[3]
     *      )
     *
     *      =
     *      max(
     *          0,
     *          0 + 1 + 1
     *      )
     *
     *      = 2
     *
     *
     * Therefore:
     *
     *      answer[2] = 2
     *
     *
     * -------------------------------------------------------------------------
     * Calculate answer[3]
     * -------------------------------------------------------------------------
     *
     * Remove subtree 3.
     *
     * Remaining:
     *
     *             1
     *            /
     *           2
     *          / \
     *         4   5
     *
     *
     * Height = 2.
     *
     *
     * Formula:
     *
     *      answer[3]
     *      =
     *      max(
     *          0,
     *          0 + 1 + height[2]
     *      )
     *
     *      =
     *      max(0, 1 + 1)
     *
     *      = 2
     *
     *
     * Therefore:
     *
     *      answer[3] = 2
     *
     *
     * -------------------------------------------------------------------------
     * Calculate answer[4]
     * -------------------------------------------------------------------------
     *
     * To calculate answer[4], we're inside subtree 2.
     *
     *
     * Current:
     *
     *      node = 2
     *      depth = 1
     *      outsideHeight = 2
     *
     *
     * Why outsideHeight = 2?
     *
     * Because if subtree 4 is removed, we can still use:
     *
     *      1 -> 3 -> 6
     *
     * which has height 2.
     *
     *
     * Therefore:
     *
     *      answer[4] = 2
     *
     *
     * -------------------------------------------------------------------------
     * Calculate answer[5]
     * -------------------------------------------------------------------------
     *
     * Same idea:
     *
     * If 5 is removed:
     *
     *
     *             1
     *            / \
     *           2   3
     *          /     \
     *         4       6
     *
     *
     * Height remains:
     *
     *      2
     *
     *
     * Therefore:
     *
     *      answer[5] = 2
     *
     *
     * =========================================================================
     * FINAL answer ARRAY
     * =========================================================================
     *
     *      answer[1] = not relevant
     *      answer[2] = 2
     *      answer[3] = 2
     *      answer[4] = 2
     *      answer[5] = 2
     *      answer[6] = 2
     *
     */


    // =========================================================================
    // WHY THIS IS O(N + M)
    // =========================================================================

    /*
     *
     * Naive approach:
     *
     *      for every query:
     *
     *          remove subtree
     *          calculate height
     *
     *
     * Worst case:
     *
     *      O(n) per query
     *
     *
     * Therefore:
     *
     *      O(n * m)
     *
     *
     * With n = 500 and m = 400:
     *
     *      500 * 400 = 200,000
     *
     * This is actually acceptable under these constraints.
     *
     *
     * BUT the more important algorithmic idea is:
     *
     *      We can precompute the answer for every node.
     *
     *
     * First DFS:
     *
     *      O(n)
     *
     * Second DFS:
     *
     *      O(n)
     *
     * Answer queries:
     *
     *      O(m)
     *
     *
     * Total:
     *
     *      O(n + n + m)
     *
     *      = O(n + m)
     *
     *
     * Space:
     *
     *      height[]  -> O(n)
     *      answer[]  -> O(n)
     *      recursion -> O(h)
     *
     *
     * Total:
     *
     *      O(n)
     *
     */


    // =========================================================================
    // THE ONE FORMULA TO REMEMBER
    // =========================================================================

    /*
     *
     *
     * Suppose:
     *
     *                   P
     *                  / \
     *                 X   S
     *
     *
     * We want:
     *
     *      answer[X]
     *
     *
     * Remove X's entire subtree.
     *
     *
     * The surviving tree can get its height from:
     *
     *
     * 1. Something that was already outside P
     *
     *          outsideHeight
     *
     *
     * 2. P's other child S
     *
     *          depth[P]
     *              +
     *          edge P -> S
     *              +
     *          height[S]
     *
     *
     * Therefore:
     *
     *
     *      answer[X] =
     *
     *      max(
     *          outsideHeight,
     *          depth[P] + 1 + height[S]
     *      )
     *
     *
     * This is the entire trick.
     *
     */
}
```

## The mental model

The hardest part isn't the code. It's understanding what `outsideHeight` means.

Imagine you're standing at node `X`:

```text
              parent
             /      \
            X      sibling
```

and you're told:

> "Delete everything under X."

What can still survive?

```text
                root
                 |
                ...
                 |
               parent
               /    \
           DELETED  sibling
```

So the remaining longest path has only **two possible sources**:

```text
                     parent
                    /      \
                   X      sibling
                  ❌         |
                             ...
```

### Source 1 — Something was already outside `parent`

```text
outsideHeight
```

### Source 2 — Go through `sibling`

```text
root → ... → parent → sibling → deepest node
```

which gives:

```text
depth[parent] + 1 + height[sibling]
```

Therefore:

```text
answer[X] = max(
    outsideHeight,
    depth[parent] + 1 + height[sibling]
)
```

That's the central insight.

### One small implementation improvement

Since your constraint explicitly says:

```text
1 <= Node.data <= n
```

I'd actually pass `n` into the method rather than hard-code:

```java
int n = 500;
```

So in a cleaner submission, use:

```java
height = new int[n + 1];
answer = new int[n + 1];
```

where `n` is the actual number of nodes.

Also, the `outsideHeight` for the root is conventionally initialized to `0` here because the root itself is guaranteed not to be queried. The important values are propagated to its children.
