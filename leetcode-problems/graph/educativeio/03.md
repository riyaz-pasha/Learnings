# 🧠 Key Observation (Interview Gold)

In a **star graph**:

* One node (center) connects to **ALL others**
* So its **degree = n - 1**
* Every other node has degree = 1

👉 That means:

> The center node must appear in **every edge**

---

# ⚡ Even Stronger Insight (1-Line Trick)

You don’t even need to check all edges.

👉 Look at just **first 2 edges**:

```
edges[0] = [a, b]
edges[1] = [c, d]
```

The **common node between them = CENTER**

---

# ✅ Approach 1: O(1) Optimal (Using First 2 Edges)

### 💡 Idea:

* Center node must be common in both edges

---

## ✅ Code (Clean + Interview Ready)

```java
public class FindCenter {

    public static int findCenter(int[][] edges) {

        // Extract first two edges
        int a = edges[0][0];
        int b = edges[0][1];
        int c = edges[1][0];
        int d = edges[1][1];

        /*
         * Core Logic:
         * Since it's a STAR graph:
         * - Center node appears in EVERY edge
         * - So it MUST be common between first 2 edges
         *
         * Cases:
         * edges[0] = [a, b]
         * edges[1] = [c, d]
         *
         * If a matches any of c or d → a is center
         * else → b is center
         */

        if (a == c || a == d) {
            return a;
        } else {
            return b;
        }
    }
}
```

---

## ⏱ Complexity

| Metric | Value    |
| ------ | -------- |
| Time   | **O(1)** |
| Space  | **O(1)** |

## 🧠 How to Think (Important for Interviews)

1. **Translate problem → graph properties**

   * Star graph ⇒ one node connected to all

2. **Convert to degree thinking**

   * Center node degree = n-1

3. **Minimize work**

   * Instead of counting degrees for all nodes…
   * Just find a node that appears **twice quickly**

👉 That’s why only first 2 edges are enough

# 🧱 Approach 2: Degree Counting (Brute but General)

### 💡 Idea:

* Count how many times each node appears
* Node with max frequency = center

---

## ✅ Code

```java
import java.util.*;

public class FindCenterDegree {

    public static int findCenter(int[][] edges) {

        /*
         * Step 1: Count degrees (frequency of appearance)
         */
        Map<Integer, Integer> degree = new HashMap<>();

        for (int[] edge : edges) {
            degree.put(edge[0], degree.getOrDefault(edge[0], 0) + 1);
            degree.put(edge[1], degree.getOrDefault(edge[1], 0) + 1);
        }

        /*
         * Step 2: Find node with max degree
         * In star graph → degree = n-1
         */
        int answer = -1;

        for (Map.Entry<Integer, Integer> entry : degree.entrySet()) {
            if (entry.getValue() == edges.length) {
                answer = entry.getKey();
                break;
            }
        }

        return answer;
    }
}
```

---

## ⏱ Complexity

| Metric | Value    |
| ------ | -------- |
| Time   | **O(n)** |
| Space  | **O(n)** |
