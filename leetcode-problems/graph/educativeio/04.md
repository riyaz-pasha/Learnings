This is a **classic graph problem** and one of the most important interview patterns.

---

# 🔥 Core Insight (VERY IMPORTANT)

A graph is a **valid tree** **iff**:

### ✅ 1. It is **connected**

→ Every node is reachable

### ✅ 2. It has **no cycles**

---

# 💡 Even Better Shortcut

A graph is a tree **iff**:

```
Number of edges == n - 1  AND  No cycles
```

👉 Actually, if edges == n-1 and graph is connected → automatically no cycles
👉 OR if edges == n-1 and no cycles → automatically connected

So we can optimize checks smartly.

---

# 🧠 How to Think in Interview

Ask yourself:

> "What defines a tree?"

* Minimal edges → `n - 1`
* No redundancy → no cycle
* Fully reachable → connected

Then think:

👉 "Cycle detection + connectivity check = answer"

# 🧩 Approach 1: DFS (Cycle Detection + Connectivity)

---

## 🚀 Idea

* Build graph (adjacency list)
* DFS traversal
* Track visited nodes
* Detect cycle using **parent tracking**
* Finally check if all nodes visited

---

## ✅ Java Code (Detailed)

```java
import java.util.*;

/**
 * ============================================================
 * APPROACH 1: DFS (Cycle Detection + Connectivity)
 * ============================================================
 *
 * THINKING:
 * - Tree must be connected + no cycle
 *
 * HOW DFS HELPS:
 * - Detect cycle using parent tracking
 * - Check connectivity using visited array
 *
 * ============================================================
 */

public class GraphValidTreeDFS {

    public boolean validTree(int n, int[][] edges) {

        // 🔥 IMPORTANT OPTIMIZATION
        // Tree MUST have exactly n-1 edges
        if (edges.length != n - 1) {
            return false;
        }

        // Step 1: Build graph (Adjacency List)
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
        }

        for (int[] edge : edges) {
            graph.get(edge[0]).add(edge[1]);
            graph.get(edge[1]).add(edge[0]);
        }

        // Step 2: Visited array
        boolean[] visited = new boolean[n];

        // Step 3: Run DFS from node 0
        if (hasCycle(0, -1, graph, visited)) {
            return false; // ❌ Cycle found
        }

        // Step 4: Check connectivity
        // All nodes must be visited
        for (boolean v : visited) {
            if (!v) return false;
        }

        return true;
    }

    /**
     * DFS function to detect cycle
     *
     * @param node   current node
     * @param parent parent node (to avoid false cycle detection)
     */
    private boolean hasCycle(int node, int parent,
                             List<List<Integer>> graph,
                             boolean[] visited) {

        visited[node] = true;

        for (int neighbor : graph.get(node)) {

            // Case 1: Not visited → go deeper
            if (!visited[neighbor]) {
                if (hasCycle(neighbor, node, graph, visited)) {
                    return true;
                }
            }
            // Case 2: Already visited AND not parent → cycle
            else if (neighbor != parent) {
                return true;
            }
        }

        return false;
    }
}
```

---

## ⏱ Complexity

* **Time:** `O(V + E)`
* **Space:** `O(V + E)`

# 🧩 Approach 2: BFS (Same Logic Iteratively)

---

## 🚀 Idea

* Same as DFS but using queue
* Track parent in queue

---

## ✅ Code

```java
import java.util.*;

/**
 * ============================================================
 * APPROACH 2: BFS (Cycle Detection + Connectivity)
 * ============================================================
 *
 * Same idea as DFS but iterative
 *
 * ============================================================
 */

public class GraphValidTreeBFS {

    public boolean validTree(int n, int[][] edges) {

        if (edges.length != n - 1) return false;

        // Build graph
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());

        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        boolean[] visited = new boolean[n];

        Queue<int[]> queue = new LinkedList<>();
        // {node, parent}
        queue.offer(new int[]{0, -1});
        visited[0] = true;

        while (!queue.isEmpty()) {

            int[] curr = queue.poll();
            int node = curr[0];
            int parent = curr[1];

            for (int neighbor : graph.get(node)) {

                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    queue.offer(new int[]{neighbor, node});
                }
                else if (neighbor != parent) {
                    return false; // cycle
                }
            }
        }

        // Check connectivity
        for (boolean v : visited) {
            if (!v) return false;
        }

        return true;
    }
}
```

# 🧩 Approach 3: Union-Find (BEST for Interviews 🔥)

---

## 🚀 Why this is powerful

* Directly detects cycles
* Naturally handles connectivity

---

## 🧠 Thinking

* Initially all nodes separate
* For every edge:

  * If both nodes already connected → cycle ❌
  * Else union them

---

## ✅ Code (Modern Java Style)

```java
import java.util.*;

/**
 * ============================================================
 * APPROACH 3: UNION FIND (Disjoint Set) ⭐ BEST
 * ============================================================
 *
 * THINKING:
 * - If two nodes already share same parent → cycle
 * - Else union them
 *
 * ============================================================
 */

public class GraphValidTreeUF {

    public boolean validTree(int n, int[][] edges) {

        // Tree must have exactly n-1 edges
        if (edges.length != n - 1) return false;

        UnionFind uf = new UnionFind(n);

        for (int[] edge : edges) {

            int u = edge[0];
            int v = edge[1];

            // If already connected → cycle
            if (!uf.union(u, v)) {
                return false;
            }
        }

        return true;
    }

    /**
     * Union-Find with Path Compression + Rank
     */
    static class UnionFind {

        private final int[] parent;
        private final int[] rank;

        UnionFind(int n) {
            parent = new int[n];
            rank = new int[n];

            for (int i = 0; i < n; i++) {
                parent[i] = i;
            }
        }

        /**
         * Find root with path compression
         */
        int find(int x) {
            if (parent[x] != x) {
                parent[x] = find(parent[x]); // path compression
            }
            return parent[x];
        }

        /**
         * Union two nodes
         * @return false if already connected (cycle)
         */
        boolean union(int x, int y) {

            int rootX = find(x);
            int rootY = find(y);

            if (rootX == rootY) {
                return false; // cycle detected
            }

            // Union by rank
            if (rank[rootX] > rank[rootY]) {
                parent[rootY] = rootX;
            } else if (rank[rootX] < rank[rootY]) {
                parent[rootX] = rootY;
            } else {
                parent[rootY] = rootX;
                rank[rootX]++;
            }

            return true;
        }
    }
}
```

---

## ⏱ Complexity

* **Time:** `O(E * α(V)) ≈ O(E)`
* **Space:** `O(V)`
