This is a classic **Bitmask + BFS** problem.

The important insight is that **the current node alone is not enough to describe our state**.

We also need to know:

> **Which nodes have we already visited?**

That gives us the state:

```text
(currentNode, visitedNodes)
```

Because `n <= 12`, we can represent `visitedNodes` efficiently using a **bitmask**.

---

# 1. Why ordinary BFS isn't enough

Suppose:

```text
0 --- 1 --- 2
```

If we are currently at node `1`, these two situations are different:

```text
Situation A:
visited = {0, 1}

Situation B:
visited = {1, 2}
```

We're at the same node:

```text
currentNode = 1
```

but we've visited different sets of nodes.

That matters because our goal is:

```text
visit EVERY node
```

So the state cannot simply be:

```text
node
```

It has to be:

```text
node + visited set
```

---

# 2. Represent the visited set with a bitmask

Since:

```text
n <= 12
```

we can use an integer.

For:

```text
n = 4
```

suppose we've visited:

```text
{0, 2, 3}
```

Then:

```text
node:       3 2 1 0
            ↓ ↓ ↓ ↓
visited:    1 1 0 1
```

The bitmask is:

```text
1101
```

which is:

```text
13
```

We can check whether node `x` has been visited:

```java
(mask & (1 << x)) != 0
```

We can mark node `x` as visited:

```java
mask | (1 << x)
```

---

# 3. What does a BFS state mean?

We'll use:

```java
record State(int node, int visitedMask)
```

For example:

```text
State(2, 101101)
```

means:

```text
current node = 2

visited:
node 0 → yes
node 1 → no
node 2 → yes
node 3 → yes
node 4 → no
node 5 → yes
```

This is the complete information needed to continue the search.

---

# 4. Why can we start BFS from every node?

The problem says:

> You may start from any node.

Therefore, the shortest path might start anywhere.

So initially we have:

```text
State(0, 000001)
State(1, 000010)
State(2, 000100)
...
State(n-1, 100000...)
```

All of these have distance:

```text
0
```

We can put **all of them into the BFS queue initially**.

This is called **multi-source BFS**.

---

# 5. Example

Consider:

```text
0 --- 1 --- 2
      |
      3
```

We need to visit:

```text
{0,1,2,3}
```

Start from node `0`:

```text
0
↓
1
↓
2
```

Then we'd need to go back:

```text
0 → 1 → 2 → 1 → 3
```

Length:

```text
4
```

But starting from node `2`:

```text
2 → 1 → 0 → 1 → 3
```

also gives:

```text
4
```

The algorithm doesn't need us to choose the starting point manually.

It starts BFS from all nodes:

```text
0
1
2
3
```

and finds the shortest overall answer.

---

# 6. Why BFS guarantees the shortest answer

Every move from one graph node to another costs exactly:

```text
1
```

We're looking for the minimum number of moves.

That's exactly what BFS is designed for.

The only difference from normal BFS is that the state is larger:

```text
normal BFS:
(node)

this problem:
(node, visitedMask)
```

So we're really doing BFS over a **state graph**.

# 8. The `visited` array

A very important optimization is:

```java
boolean[][] visited
```

where:

```text
visited[node][mask]
```

means:

> Have we already reached this node with exactly this set of visited nodes?

For:

```text
n = 4
```

there are:

```text
4 × 2^4 = 64
```

possible states.

In general:

```text
n × 2^n
```

states.

Because:

```text
n <= 12
```

we have at most:

```text
12 × 4096
= 49,152
```

states.

That's very manageable.

# 9. Fully commented Java solution

```java
import java.util.*;

/**
 * Problem:
 *
 * Find the shortest path that visits every node in an
 * undirected connected graph.
 *
 * We may:
 * - start anywhere
 * - finish anywhere
 * - revisit nodes
 * - reuse edges
 *
 * ------------------------------------------------------------
 * Core idea: Bitmask + BFS
 * ------------------------------------------------------------
 *
 * The current node alone is NOT enough to describe our state.
 *
 * Example:
 *
 *     current node = 2
 *
 * Could have:
 *
 *     visited = {0, 1, 2}
 *
 * or:
 *
 *     visited = {2, 3}
 *
 * These are different situations.
 *
 * Therefore our BFS state is:
 *
 *     (currentNode, visitedMask)
 *
 * Since n <= 12, we can represent the set of visited
 * nodes using an integer bitmask.
 *
 * ------------------------------------------------------------
 *
 * Example:
 *
 * n = 4
 *
 * visited nodes = {0, 2, 3}
 *
 * bit representation:
 *
 *     node:       3 2 1 0
 *                 ↓ ↓ ↓ ↓
 *     visited:    1 1 0 1
 *
 *     mask = 1101
 *
 * ------------------------------------------------------------
 *
 * Because every move costs exactly 1, BFS gives the
 * shortest number of moves.
 *
 * We start BFS from EVERY node because the starting
 * node can be arbitrary.
 *
 * This is multi-source BFS.
 */
public class ShortestPathVisitingAllNodes {

    /**
     * Represents one state in our BFS.
     *
     * node:
     *     Current graph node.
     *
     * visitedMask:
     *     Bitmask representing all nodes visited so far.
     */
    record State(int node, int visitedMask) {}

    public int shortestPathLength(int[][] graph) {

        int numberOfNodes = graph.length;

        /*
         * If there is only one node, we have already
         * visited every node.
         *
         * Answer = 0 moves.
         */
        if (numberOfNodes == 1) {
            return 0;
        }

        /*
         * If there are n nodes:
         *
         *     1 << n
         *
         * gives us 2^n possible masks.
         *
         * Example:
         *
         * n = 3
         *
         *     1 << 3 = 8
         *
         * Masks range from:
         *
         *     000
         * to:
         *     111
         */
        int numberOfMasks = 1 << numberOfNodes;

        /*
         * allVisitedMask represents the situation where
         * every node has been visited.
         *
         * Example:
         *
         * n = 4
         *
         *     allVisitedMask = 1111
         */
        int allVisitedMask = (1 << numberOfNodes) - 1;

        /*
         * visited[node][mask] means:
         *
         * "Have we already reached 'node' after visiting
         * exactly the set of nodes represented by 'mask'?"
         *
         * There are at most:
         *
         *     n * 2^n
         *
         * states.
         */
        boolean[][] visited =
                new boolean[numberOfNodes][numberOfMasks];

        /*
         * We need a queue because this is BFS.
         */
        Queue<State> queue = new ArrayDeque<>();

        /*
         * --------------------------------------------------------
         * Multi-source BFS
         * --------------------------------------------------------
         *
         * The problem allows us to start at ANY node.
         *
         * Therefore, start BFS from every node.
         *
         * If we start at node i:
         *
         *     current node = i
         *
         *     visited mask has only bit i set.
         *
         * Example for n = 4:
         *
         * start at 0:
         *     0001
         *
         * start at 1:
         *     0010
         *
         * start at 2:
         *     0100
         *
         * start at 3:
         *     1000
         */
        for (int node = 0; node < numberOfNodes; node++) {

            int startingMask = 1 << node;

            queue.offer(
                    new State(node, startingMask)
            );

            visited[node][startingMask] = true;
        }

        /*
         * Number of edges/moves made so far.
         *
         * All initial states are at distance 0.
         */
        int distance = 0;

        /*
         * --------------------------------------------------------
         * BFS
         * --------------------------------------------------------
         */
        while (!queue.isEmpty()) {

            /*
             * Process one BFS level at a time.
             *
             * Every state in this level requires exactly
             * 'distance' moves from its starting point.
             */
            int currentLevelSize = queue.size();

            for (int i = 0; i < currentLevelSize; i++) {

                State currentState = queue.poll();

                int currentNode = currentState.node();
                int currentMask = currentState.visitedMask();

                /*
                 * If all bits are set, every node has been
                 * visited.
                 *
                 * Because BFS explores states in increasing
                 * distance order, this is the shortest answer.
                 */
                if (currentMask == allVisitedMask) {
                    return distance;
                }

                /*
                 * Explore all neighbors of the current node.
                 */
                for (int neighbor : graph[currentNode]) {

                    /*
                     * Mark the neighbor as visited.
                     *
                     * OR operation keeps all previously
                     * visited nodes and adds this neighbor.
                     *
                     * Example:
                     *
                     * currentMask = 0101
                     * neighbor    = 1
                     *
                     *     1 << 1 = 0010
                     *
                     * newMask:
                     *
                     *     0101
                     * OR  0010
                     *     ----
                     *     0111
                     */
                    int newMask =
                            currentMask | (1 << neighbor);

                    /*
                     * If we have already reached this same
                     * node with this exact visited set,
                     * processing it again cannot help.
                     */
                    if (visited[neighbor][newMask]) {
                        continue;
                    }

                    /*
                     * Mark the state as visited and add it
                     * to the next BFS level.
                     */
                    visited[neighbor][newMask] = true;

                    queue.offer(
                            new State(neighbor, newMask)
                    );
                }
            }

            /*
             * All states at the current distance have been
             * processed.
             *
             * Moving to the next BFS level means one more
             * edge/move.
             */
            distance++;
        }

        /*
         * The input graph is guaranteed to be connected,
         * so theoretically this should never happen.
         *
         * Return -1 for completeness.
         */
        return -1;
    }
}
```

# 11. Why can we revisit nodes?

This is a very important detail.

The problem explicitly allows:

> Revisit nodes and reuse edges.

Consider:

```text
0 --- 1 --- 2
      |
      3
```

If we start at `0`, we might need:

```text
0 → 1 → 2 → 1 → 3
```

Notice:

```text
1
```

was visited twice.

That's completely valid.

Our algorithm allows this because:

```text
visited[node][mask]
```

does **not** mean:

> "This graph node can never be visited again."

It means:

> "We have already processed this exact state."

For example:

```text
(1, 0011)
```

and:

```text
(1, 1111)
```

are completely different states.

Even though we're at node `1` both times, the second state has visited more nodes.

---

# 12. Why `visited[node]` alone would be wrong

This is a common mistake.

You might try:

```java
boolean[] visited;
```

and say:

```text
"I've already visited node 1, so don't visit it again."
```

That would be incorrect.

Example:

```text
0 --- 1 --- 2
      |
      3
```

Suppose we reach node `1` from `0`:

```text
current state:
node = 1
visited = {0,1}
```

Later we might reach node `1` again:

```text
current state:
node = 1
visited = {0,1,2,3}
```

The second state is much better because we've already visited all nodes.

So:

```text
node alone
```

doesn't define the state.

We need:

```text
node + visitedMask
```

# 14. Complexity

There are at most:

```text
n × 2^n
```

states.

For every state, we examine the neighbors of the current node.

Let:

```text
E = number of edges
```

The complexity can be expressed as:

```text
O(2^n × (n + E))
```

For a dense graph:

```text
E = O(n²)
```

so:

```text
O(2^n × n²)
```

Space:

```text
O(n × 2^n)
```

for the `visited` states and BFS queue.

With:

```text
n <= 12
```

this is easily manageable.

# 15. The deeper graph interpretation

This problem is actually **BFS on a new graph**.

The original graph might be:

```text
0 --- 1
|     |
2 --- 3
```

But our algorithm creates an implicit **state graph**.

Each state is:

```text
(node, visitedMask)
```

For example:

```text
(0, 0001)
(1, 0011)
(2, 0101)
(3, 1111)
```

There is an edge:

```text
(node, mask)
       |
       | move to neighbor
       ↓
(neighbor, newMask)
```

where:

```java
newMask = mask | (1 << neighbor);
```

So we're not actually doing BFS on the original graph.

We're doing:

```text
BFS
 ↓
state graph
 ↓
(node + visited set)
```

This is one of the most useful patterns to recognize in graph problems.
