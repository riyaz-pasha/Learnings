This is a **classic greedy + prefix sum + binary search** problem. Let’s build intuition first and then code it in your preferred **interview template style**.

---

# 🧠 Key Insight (VERY IMPORTANT)

👉 You want **maximum number of elements** such that:

```
sum ≤ query
```

### ❓ Which elements should we pick?

To maximize count, we should pick **smallest elements first**.

> 💡 Greedy choice:
> Sort the array and keep taking smallest values.

---

# 🔥 Step-by-Step Approach

### 1. Sort the array

```
nums = [4, 2, 1, 3] → [1, 2, 3, 4]
```

---

### 2. Build Prefix Sum

```
prefix[i] = sum of first i elements
```

Example:

```
nums   = [1, 2, 3, 4]
prefix = [1, 3, 6, 10]
```

---

### 3. For each query → Binary Search

Find:

```
maximum index i such that prefix[i] ≤ query
```

That index + 1 = answer

---

# 🚀 Solution 1: Binary Search (Optimal)

## ⏱ Complexity

* Sorting: `O(n log n)`
* Prefix sum: `O(n)`
* Each query: `O(log n)`
* Total: `O((n + m) log n)`

---

## ✅ Java (Interview Template Style — Your Preference)

```java
import java.util.*;

/**
 * ============================================================
 * 🔥 Maximum Subsequence Size with Sum ≤ Query
 * ============================================================
 *
 * IDEA:
 * 1. Sort the array → greedy: pick smallest elements first
 * 2. Build prefix sum → cumulative sums
 * 3. For each query → binary search on prefix array
 *
 * WHY BINARY SEARCH WORKS?
 * Prefix array is monotonically increasing → perfect for BS
 *
 * ============================================================
 */
public class MaxSubsequenceSize {

    public static void main(String[] args) {
        int[] nums = {4, 2, 1, 3};
        int[] queries = {1, 5, 8};

        System.out.println(Arrays.toString(answerQueries(nums, queries)));
    }

    public static int[] answerQueries(int[] nums, int[] queries) {

        // Step 1: Sort (Greedy)
        Arrays.sort(nums);

        // Step 2: Prefix sum
        int n = nums.length;
        int[] prefix = new int[n];

        prefix[0] = nums[0];
        for (int i = 1; i < n; i++) {
            prefix[i] = prefix[i - 1] + nums[i];
        }

        // Step 3: Process queries
        int[] answer = new int[queries.length];

        for (int i = 0; i < queries.length; i++) {
            answer[i] = binarySearchMaxLength(prefix, queries[i]);
        }

        return answer;
    }

    /**
     * 🔍 Binary Search Template (LAST TRUE)
     *
     * Find largest index i such that:
     * prefix[i] <= target
     *
     * Monotonic Condition:
     * TRUE TRUE TRUE FALSE FALSE
     *
     * We want LAST TRUE
     */
    private static int binarySearchMaxLength(int[] prefix, int target) {

        int low = 0;
        int high = prefix.length - 1;

        int answerIndex = -1; // stores last valid index

        while (low <= high) {
            int mid = low + (high - low) / 2;

            if (prefix[mid] <= target) {
                // ✅ valid → try to expand
                answerIndex = mid;
                low = mid + 1;
            } else {
                // ❌ too large → shrink
                high = mid - 1;
            }
        }

        // index + 1 = count of elements
        return answerIndex + 1;
    }
}
```

```java
public static int[] bruteForce(int[] nums, int[] queries) {

    Arrays.sort(nums);

    int[] result = new int[queries.length];

    for (int i = 0; i < queries.length; i++) {
        int sum = 0;
        int count = 0;

        for (int num : nums) {
            if (sum + num <= queries[i]) {
                sum += num;
                count++;
            } else {
                break;
            }
        }

        result[i] = count;
    }

    return result;
}
```

# 🧠 Core Idea (Offline Trick)

Instead of:

> For each query → binary search

We do:

> Process queries in **sorted order** and **grow prefix only once**

---

# ⚡ Key Transformation

### Step 1: Sort nums

Same as before → greedy smallest first

---

### Step 2: Sort queries with index

We can’t lose original order → so store:

```java
(queryValue, originalIndex)
```

---

### Step 3: Two Pointers

* Maintain:

  * `currentSum`
  * `count` (how many elements taken)
* Traverse sorted queries
* Keep adding elements while possible

---

# 🔥 Why This Works

Because:

```text
If q1 ≤ q2 ≤ q3
Then:
answer(q1) ≤ answer(q2) ≤ answer(q3)
```

👉 So we **never need to recompute from scratch**

---

# 🚀 Complexity

* Sort nums: `O(n log n)`
* Sort queries: `O(m log m)`
* Single pass: `O(n + m)`

✅ Total: `O(n log n + m log m)`
(No binary search per query)

---

# ✅ Java (Clean + Interview Ready)

```java
import java.util.*;

/**
 * ============================================================
 * 🔥 OFFLINE QUERIES + TWO POINTERS
 * ============================================================
 *
 * IDEA:
 * 1. Sort nums (greedy smallest first)
 * 2. Sort queries with index
 * 3. Use 2 pointers to build prefix sum gradually
 *
 * WHY IT WORKS?
 * Queries are processed in increasing order,
 * so we reuse previous computation.
 *
 * ============================================================
 */
public class MaxSubsequenceOffline {

    // Record (Java 24 style) for query + index
    record Query(int value, int index) {}

    public static void main(String[] args) {
        int[] nums = {4, 2, 1, 3};
        int[] queries = {1, 5, 8};

        System.out.println(Arrays.toString(answerQueries(nums, queries)));
    }

    public static int[] answerQueries(int[] nums, int[] queries) {

        // Step 1: Sort nums
        Arrays.sort(nums);

        int n = nums.length;
        int m = queries.length;

        // Step 2: Convert queries → (value, index)
        Query[] qArr = new Query[m];
        for (int i = 0; i < m; i++) {
            qArr[i] = new Query(queries[i], i);
        }

        // Step 3: Sort queries by value
        Arrays.sort(qArr, Comparator.comparingInt(Query::value));

        int[] answer = new int[m];

        int currentSum = 0;
        int count = 0;  // pointer on nums

        /**
         * Two Pointer Logic:
         *
         * For each query:
         * keep adding nums[count] while sum <= query
         */
        for (Query q : qArr) {

            while (count < n && currentSum + nums[count] <= q.value) {
                currentSum += nums[count];
                count++;
            }

            // store answer in original index
            answer[q.index] = count;
        }

        return answer;
    }
}
```

# 🚀 Fenwick Tree Approach

## 🧩 Idea

We maintain TWO Fenwick Trees:

1. **Count Tree** → how many elements exist
2. **Sum Tree** → sum of elements

---

## 🧠 Coordinate Compression

Since values up to `1e5`, we map values → indices

---

## 🔍 Query Goal

For a given `target`, we need:

```text
Max count such that sum ≤ target
```

👉 This becomes:

> Find largest prefix in Fenwick (by value) where sum ≤ target

---

# 🔥 Core Trick: Binary Search ON Fenwick Tree

We don't binary search array
👉 We binary search **Fenwick prefix**

---

# ✅ Java Implementation (Interview-Level)

```java
import java.util.*;

/**
 * ============================================================
 * 🔥 Fenwick Tree (BIT) Approach
 * ============================================================
 *
 * USE CASE:
 * - Dynamic array
 * - Insert/remove elements
 * - Query: max elements with sum ≤ target
 *
 * IDEA:
 * Maintain:
 * 1. Count BIT → frequency
 * 2. Sum BIT → cumulative sum
 *
 * Then:
 * Binary search on BIT to find max prefix
 *
 * ============================================================
 */
public class FenwickSolution {

    static class Fenwick {
        int n;
        long[] tree;

        Fenwick(int n) {
            this.n = n;
            this.tree = new long[n + 1];
        }

        // Add value at index
        void update(int i, long delta) {
            while (i <= n) {
                tree[i] += delta;
                i += i & -i;
            }
        }

        // Prefix sum
        long query(int i) {
            long sum = 0;
            while (i > 0) {
                sum += tree[i];
                i -= i & -i;
            }
            return sum;
        }

        /**
         * 🔍 Find largest index such that prefix sum ≤ target
         *
         * This is Fenwick's internal binary lifting
         */
        int findMaxPrefix(long target) {
            int idx = 0;
            long sum = 0;

            // Largest power of 2 <= n
            for (int bit = Integer.highestOneBit(n); bit != 0; bit >>= 1) {
                int next = idx + bit;

                if (next <= n && sum + tree[next] <= target) {
                    sum += tree[next];
                    idx = next;
                }
            }

            return idx; // compressed index
        }
    }

    public static void main(String[] args) {

        int[] nums = {4, 2, 1, 3};
        int[] queries = {1, 5, 8};

        System.out.println(Arrays.toString(solve(nums, queries)));
    }

    public static int[] solve(int[] nums, int[] queries) {

        // Step 1: Coordinate compression
        int[] sorted = nums.clone();
        Arrays.sort(sorted);

        Map<Integer, Integer> indexMap = new HashMap<>();
        for (int i = 0; i < sorted.length; i++) {
            indexMap.put(sorted[i], i + 1); // 1-based
        }

        int n = sorted.length;

        Fenwick countBIT = new Fenwick(n);
        Fenwick sumBIT = new Fenwick(n);

        // Step 2: Insert all elements
        for (int num : nums) {
            int idx = indexMap.get(num);
            countBIT.update(idx, 1);
            sumBIT.update(idx, num);
        }

        int[] ans = new int[queries.length];

        for (int i = 0; i < queries.length; i++) {

            int left = 1, right = n;
            int bestIndex = 0;

            /**
             * Binary search on compressed values
             * to find max prefix sum ≤ query
             */
            while (left <= right) {
                int mid = (left + right) / 2;

                long sum = sumBIT.query(mid);

                if (sum <= queries[i]) {
                    bestIndex = mid;
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }

            // Count how many elements in that prefix
            ans[i] = (int) countBIT.query(bestIndex);
        }

        return ans;
    }
}
```

# ✅ Java Implementation (TreeMap)

```java
import java.util.*;

/**
 * ============================================================
 * 🔥 TreeMap Approach (Prefix Sum Mapping)
 * ============================================================
 *
 * IDEA:
 * prefixSum → count
 *
 * Query:
 * floorEntry(query)
 *
 * ============================================================
 */
public class TreeMapSolution {

    public static int[] answerQueries(int[] nums, int[] queries) {

        Arrays.sort(nums);

        // prefixSum → count
        TreeMap<Integer, Integer> map = new TreeMap<>();

        int sum = 0;

        for (int i = 0; i < nums.length; i++) {
            sum += nums[i];
            map.put(sum, i + 1);
        }

        int[] ans = new int[queries.length];

        for (int i = 0; i < queries.length; i++) {

            var entry = map.floorEntry(queries[i]);

            if (entry == null) {
                ans[i] = 0;
            } else {
                ans[i] = entry.getValue();
            }
        }

        return ans;
    }
}
```
