This is the classic **LeetCode 166 — Fraction to Recurring Decimal** problem.

The key idea is:

> **When doing long division, if the same remainder appears again, the digits between the two occurrences will repeat.**

### Java 24 — HashMap solution

```java
import java.util.*;

class Solution {

    public String fractionToDecimal(int numerator, int denominator) {

        // ------------------------------------------------------------
        // 1. Handle zero numerator
        // ------------------------------------------------------------
        if (numerator == 0) {
            return "0";
        }

        StringBuilder result = new StringBuilder();

        // ------------------------------------------------------------
        // 2. Determine the sign
        //
        // If exactly one of numerator/denominator is negative,
        // the answer is negative.
        // ------------------------------------------------------------
        if ((numerator < 0) ^ (denominator < 0)) {
            result.append("-");
        }

        // ------------------------------------------------------------
        // 3. Convert to long
        //
        // IMPORTANT:
        // Integer.MIN_VALUE = -2^31 cannot be safely converted
        // to positive int.
        //
        // Using long avoids overflow when taking abs().
        // ------------------------------------------------------------
        long num = Math.abs((long) numerator);
        long den = Math.abs((long) denominator);

        // ------------------------------------------------------------
        // 4. Add the integer part
        // ------------------------------------------------------------
        result.append(num / den);

        // Remainder after extracting integer part
        long remainder = num % den;

        // No fractional part
        if (remainder == 0) {
            return result.toString();
        }

        result.append(".");

        // ------------------------------------------------------------
        // 5. Map:
        //     remainder -> position in result
        //
        // Why?
        //
        // During long division:
        //
        // remainder -> multiply by 10 -> digit + new remainder
        //
        // If we see the SAME remainder again, the exact same
        // sequence of digits will repeat.
        //
        // Example:
        //
        // 1 / 6
        //
        // remainder = 1
        // 10 / 6 = 1, remainder = 4
        // 40 / 6 = 6, remainder = 4
        //
        // remainder 4 appeared before, so "6" repeats.
        //
        // Result = 0.1(6)
        // ------------------------------------------------------------
        Map<Long, Integer> remainderPosition = new HashMap<>();

        while (remainder != 0) {

            // --------------------------------------------------------
            // If this remainder has already appeared:
            //
            // Everything from that previous position to the current
            // position is the repeating portion.
            // --------------------------------------------------------
            if (remainderPosition.containsKey(remainder)) {

                int repeatStart = remainderPosition.get(remainder);

                result.insert(repeatStart, "(");
                result.append(")");

                return result.toString();
            }

            // Remember where this remainder first appeared.
            remainderPosition.put(remainder, result.length());

            // --------------------------------------------------------
            // Long division step
            //
            // Example: remainder = 2
            //
            // 2 * 10 = 20
            // digit = 20 / denominator
            // remainder = 20 % denominator
            // --------------------------------------------------------
            remainder *= 10;

            result.append(remainder / den);

            remainder %= den;
        }

        // ------------------------------------------------------------
        // If remainder becomes 0, the decimal terminates.
        // Example:
        //
        // 1 / 4 -> 0.25
        // ------------------------------------------------------------
        return result.toString();
    }
}
```

## How to think about it in an interview

Think about **normal long division**.

For example:

### `1 / 6`

```text
1 / 6 = 0
remainder = 1
```

Now fractional part:

```text
remainder = 1

1 × 10 = 10
10 / 6 = 1
remainder = 4

4 × 10 = 40
40 / 6 = 6
remainder = 4
```

We got **remainder 4 again**.

That means we're back at exactly the same state:

```text
remainder 4
   ↓
40 / 6 = 6 remainder 4
   ↓
40 / 6 = 6 remainder 4
   ↓
...
```

Therefore:

```text
1 / 6 = 0.1(6)
```

---

## Why HashMap?

The important mapping is:

```text
remainder → position in StringBuilder
```

For example, while calculating `1 / 7`:

```text
remainder 1 → position 2
remainder 3 → position 3
remainder 2 → position 4
remainder 6 → position 5
remainder 4 → position 6
remainder 5 → position 7
remainder 1 → already seen at position 2
```

Therefore everything from position `2` onward repeats:

```text
0.(142857)
```

---

## Complexity

Let `d = |denominator|`.

There can be at most `d` distinct remainders:

```text
0, 1, 2, ..., d - 1
```

Therefore:

**Time:** `O(d)`

**Space:** `O(d)`

The `StringBuilder` also requires `O(d)` space for the output.

### Interview one-liner

> "I simulate long division and store the first position of every remainder. If a remainder repeats, we're in the same division state, so the digits generated since its first occurrence are the recurring portion."

### Important edge cases

```text
1 / 2       → "0.5"
1 / 4       → "0.25"
1 / 3       → "0.(3)"
1 / 6       → "0.1(6)"
1 / 7       → "0.(142857)"
-1 / 2      → "-0.5"
-1 / -2     → "0.5"
0 / 5       → "0"
```

The **most important interview trick** here is recognizing that **repeated remainder = repeated decimal cycle**.
