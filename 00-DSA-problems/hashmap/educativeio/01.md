This is the classic **“Design HashMap” (LeetCode 706)** problem — very important for interviews because it tests **fundamentals of hashing + collision handling**.

---

# 🧠 How to Think (Interview Approach)

Before coding, always clarify:

👉 Keys range: `0 → 10^6`  
👉 Operations: only `10^4` → low load → we can even use simpler designs

So you have **3 possible approaches**:

---

# ✅ Approach 1: Direct Addressing (Best for given constraints)

### 💡 Idea:
Since keys are bounded (`≤ 10^6`), we can use an **array of size 1,000,001**

- Index = key  
- Value = stored value  
- Default = `-1` (means not present)

---

## 🚀 Code (Java 24 style)

```java
import java.util.Arrays;

/**
 * Approach 1: Direct Address Table
 * 
 * Think:
 * Instead of hashing → directly map key to index
 * 
 * When to use:
 * - Key range is SMALL and bounded
 * - Memory is acceptable
 */
public class MyHashMap_DirectAddressing {

    private static final int MAX_KEY = 1_000_001;
    private final int[] map;

    public MyHashMap_DirectAddressing() {
        map = new int[MAX_KEY];
        Arrays.fill(map, -1); // -1 means no value
    }

    public void put(int key, int value) {
        map[key] = value;
    }

    public int get(int key) {
        return map[key];
    }

    public void remove(int key) {
        map[key] = -1;
    }
}
```

---

### ⏱ Complexity
- `put/get/remove` → **O(1)**
- Space → **O(10^6)**

---

### ⚠️ When NOT to use?
- If key range is huge (like `10^9`)
- Memory constraints strict

---

# ✅ Approach 2: Separate Chaining (Linked List Buckets)

### 💡 Idea:
- Use **array of buckets**
- Each bucket = **LinkedList of (key, value)**
- Handle collisions using chaining

---

## 🚀 Code

```java
import java.util.*;

/**
 * Approach 2: Separate Chaining
 * 
 * Think:
 * hash(key) → bucket
 * collisions → handled via LinkedList
 */
public class MyHashMap_Chaining {

    // Using record (Java 24 feature)
    private record Node(int key, int value) {}

    private final int SIZE = 1000; // number of buckets
    private final List<Node>[] buckets;

    public MyHashMap_Chaining() {
        buckets = new List[SIZE];
    }

    private int hash(int key) {
        return key % SIZE;
    }

    public void put(int key, int value) {
        int index = hash(key);

        if (buckets[index] == null) {
            buckets[index] = new LinkedList<>();
        }

        List<Node> bucket = buckets[index];

        // Check if key exists → update
        for (int i = 0; i < bucket.size(); i++) {
            Node node = bucket.get(i);
            if (node.key == key) {
                bucket.set(i, new Node(key, value)); // replace
                return;
            }
        }

        // Else add new
        bucket.add(new Node(key, value));
    }

    public int get(int key) {
        int index = hash(key);

        List<Node> bucket = buckets[index];
        if (bucket == null) return -1;

        for (Node node : bucket) {
            if (node.key == key) return node.value;
        }

        return -1;
    }

    public void remove(int key) {
        int index = hash(key);

        List<Node> bucket = buckets[index];
        if (bucket == null) return;

        bucket.removeIf(node -> node.key == key);
    }
}
```

---

### ⏱ Complexity
- Average → **O(1)**
- Worst → **O(N)** (if all keys collide)

---

### 🧠 Interview Insight:
👉 This is the **most expected solution**  
👉 Talk about **load factor** and resizing if asked deeper

# ✅ Approach 3: Open Addressing (Linear Probing)

### 💡 Idea:
- Store everything in array
- If collision → move forward (linear probing)

---

## 🚀 Code

```java
/**
 * Approach 3: Open Addressing (Linear Probing)
 * 
 * Think:
 * If collision → find next empty slot
 */
public class MyHashMap_OpenAddressing {

    private static final int SIZE = 20011; // prime for better distribution

    private final int[] keys;
    private final int[] values;
    private final boolean[] used;

    public MyHashMap_OpenAddressing() {
        keys = new int[SIZE];
        values = new int[SIZE];
        used = new boolean[SIZE];
    }

    private int hash(int key) {
        return key % SIZE;
    }

    public void put(int key, int value) {
        int index = hash(key);

        while (used[index] && keys[index] != key) {
            index = (index + 1) % SIZE; // linear probing
        }

        keys[index] = key;
        values[index] = value;
        used[index] = true;
    }

    public int get(int key) {
        int index = hash(key);

        while (used[index]) {
            if (keys[index] == key) {
                return values[index];
            }
            index = (index + 1) % SIZE;
        }

        return -1;
    }

    public void remove(int key) {
        int index = hash(key);

        while (used[index]) {
            if (keys[index] == key) {
                used[index] = false; // mark as deleted
                return;
            }
            index = (index + 1) % SIZE;
        }
    }
}
```

---

### ⏱ Complexity
- Average → **O(1)**
- Worst → **O(N)**

---

### ⚠️ Interview Note:
Deletion in open addressing is tricky → needs **tombstones** (we simplified here)

# 🔥 Final Comparison

| Approach | Best For | Time | Space | Interview Value |
|--------|---------|------|------|----------------|
| Direct Addressing | Small key range | O(1) | High | ⭐⭐ |
| Chaining | General case | O(1) avg | Medium | ⭐⭐⭐⭐ |
| Open Addressing | Memory optimized | O(1) avg | Low | ⭐⭐⭐ |
