One small improvement: you don't need the final loop to find the root. If you keep a `root` variable when processing the first node, the intent is clearer.

Here's a cleaned-up version with detailed tracing comments.

```java
import java.util.*;
import ds_v1.BinaryTree.TreeNode;

public class RecoverTreeFromPreorder {

    /**
     * Recover a binary tree from its preorder traversal.
     *
     * Format:
     *
     *     depth = number of '-'
     *     value = node value
     *
     * Example:
     *
     *     1-2--3--4-5--6--7
     *
     * Represents:
     *
     *             1
     *            / \
     *           2   5
     *          / \ / \
     *         3  4 6  7
     *
     * ------------------------------------------------------------
     * Key idea:
     * ------------------------------------------------------------
     *
     * The traversal is preorder:
     *
     *     node -> left -> right
     *
     * The number of '-' tells us the node's depth.
     *
     * We maintain a stack representing the path from the root
     * down to the CURRENT node.
     *
     * Example while processing node 4:
     *
     *             1
     *            /
     *           2
     *          /
     *         3
     *          \
     *           4
     *
     * Stack:
     *
     *     [4, 2, 1]
     *      ↑
     *     top
     *
     * More importantly:
     *
     *     stack.size() == current node depth + 1
     *
     * Before attaching a new node of depth D:
     *
     *     pop until stack.size() == D
     *
     * Then stack.peek() is its parent.
     *
     * ------------------------------------------------------------
     *
     * Time:  O(N)
     * Space: O(H)
     *
     * N = number of nodes
     * H = height of the tree
     */
    public TreeNode<Integer> recoverFromPreorder(String traversal) {

        int index = 0;
        int length = traversal.length();

        /*
         * Stack represents the path from the root to the
         * previously processed node.
         *
         * The TOP of the stack is always the most recently
         * processed node.
         *
         * Example:
         *
         *     1
         *    /
         *   2
         *  /
         * 3
         *
         * stack:
         *
         *     top
         *      ↓
         *     [3]
         *     [2]
         *     [1]
         */
        Deque<TreeNode<Integer>> path =
                new ArrayDeque<>();

        TreeNode<Integer> root = null;

        while (index < length) {

            // ====================================================
            // STEP 1: Read the depth
            // ====================================================
            //
            // Number of '-' characters = depth.
            //
            // Examples:
            //
            //     "1"     -> depth 0
            //     "-2"    -> depth 1
            //     "--3"   -> depth 2
            //     "---4"  -> depth 3
            //
            int depth = 0;

            while (index < length
                    && traversal.charAt(index) == '-') {

                depth++;
                index++;
            }

            // ====================================================
            // STEP 2: Read the node value
            // ====================================================
            //
            // Example:
            //
            //     "123"
            //
            // becomes integer 123.
            //
            int value = 0;

            while (index < length
                    && Character.isDigit(traversal.charAt(index))) {

                value = value * 10
                        + (traversal.charAt(index) - '0');

                index++;
            }

            TreeNode<Integer> currentNode =
                    new TreeNode<>(value);

            // The first node is always the root.
            if (root == null) {
                root = currentNode;
            }

            // ====================================================
            // STEP 3: Adjust the stack to find the parent
            // ====================================================
            //
            // Suppose the current node has depth = 2.
            //
            // We want the stack to contain exactly the nodes
            // from depth 0 through depth 1:
            //
            //     [depth 1]
            //     [depth 0]
            //
            // Then stack.peek() is the parent at depth 1.
            //
            // So:
            //
            //     while stack.size() > depth
            //
            // remove nodes until:
            //
            //     stack.size() == depth
            //
            // This is the most important stack invariant.
            //
            while (path.size() > depth) {
                path.pop();
            }

            // ====================================================
            // STEP 4: Attach current node to its parent
            // ====================================================
            //
            // If the stack is empty, this is the root.
            //
            // Otherwise:
            //
            //     stack.peek() = parent
            //
            if (!path.isEmpty()) {

                TreeNode<Integer> parent = path.peek();

                /*
                 * Because traversal is PREORDER:
                 *
                 *     parent
                 *     /
                 *    left
                 *
                 * is encountered before:
                 *
                 *     parent
                 *        \
                 *         right
                 *
                 * Therefore, the first child we encounter is
                 * always the left child.
                 *
                 * The second child is the right child.
                 */
                if (parent.left == null) {
                    parent.left = currentNode;
                } else {
                    parent.right = currentNode;
                }
            }

            // ====================================================
            // STEP 5: Push current node onto the path
            // ====================================================
            //
            // The current node may become the parent of the next
            // node in the preorder traversal.
            //
            // Example:
            //
            //     1-2--3
            //
            // After processing 2:
            //
            //     stack = [2, 1]
            //
            // So when 3 arrives, 2 is available as its parent.
            //
            path.push(currentNode);
        }

        return root;
    }
}
```

```text

```

The tree is:

```text
             1
           /   \
          2     5
         / \   / \
        3   4 6   7
```

```text

depth = 0
```

Stack is empty, so `1` becomes root.

Then:

```text
stack = [1]
```

## The key invariant

This is the part I'd remember for an interview:

> **Before attaching a node of depth `D`, make the stack size exactly `D`. Then `stack.peek()` is its parent.**

So:

```java
while (path.size() > depth) {
    path.pop();
}
```

followed by:

```java
TreeNode<Integer> parent = path.peek();
```

is the heart of the solution.

Think of the stack as:

```text
depth 0  → root
depth 1  → current parent
depth 2  → current grandparent
...
depth D-1 → parent of incoming node
```

For an incoming node at depth `D`:

```text
                 incoming
                    ↑
                 depth D

                   parent
                 depth D-1

                  parent
                 depth D-2

                    ...
                 
                   root
                 depth 0
```

So the stack needs exactly `D` nodes before we read `peek()`.

### Complexity

If there are `N` nodes:

```text
Time:  O(N)
Space: O(H)
```

Each node is pushed once and popped at most once, so although there is a `while` loop inside the main loop, the total number of stack pops is still `O(N)`.

The especially useful pattern here is:

```text
Preorder + depth
       ↓
maintain root-to-current path with stack
       ↓
depth tells us how far to pop
       ↓
stack.peek() gives parent
```

This is a very reusable tree reconstruction pattern.
