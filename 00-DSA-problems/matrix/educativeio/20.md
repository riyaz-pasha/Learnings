This is a **classic “Smallest Rectangle Enclosing Black Pixels”** problem with a **key constraint: better than O(m × n)**.

---

# 🔥 Core Insight (Interview Gold)

* You are given **one black pixel (x, y)**.
* All black pixels form **ONE connected component**.
* So instead of scanning entire matrix ❌, we can **search boundaries using Binary Search** ✅

👉 Think of it like this:

> “Instead of finding all 1s, find the **first/last row/column that contains a 1**.”

---

# 🧠 Key Idea

We need 4 boundaries:

| Boundary | Meaning                 |
| -------- | ----------------------- |
| top      | first row with a `1`    |
| bottom   | last row with a `1`     |
| left     | first column with a `1` |
| right    | last column with a `1`  |

Then:

```
Area = (bottom - top + 1) * (right - left + 1)
```

---

# ⚡ Why Binary Search Works?

Each row (or column) can be treated as:

```
Does this row contain any '1' ?
```

This gives a **monotonic pattern**:

Example for rows:

```
0 0 0 1 1 1 1 0 0
      ↑ black region
```

So we can binary search:

* First row with 1
* Last row with 1

---

# ✅ Optimal Solution — Binary Search (O(m log n + n log m))

---

## 🧾 Java Implementation (Interview Ready)

```java
import java.util.*;

public class SmallestRectangleEnclosingBlackPixels {

    public static int minArea(char[][] image, int x, int y) {

        int m = image.length;
        int n = image[0].length;

        // 🔹 Find boundaries using Binary Search
        int top = searchRows(image, 0, x, true);
        int bottom = searchRows(image, x, m - 1, false);
        int left = searchCols(image, 0, y, true);
        int right = searchCols(image, y, n - 1, false);

        // 🔹 Area calculation
        return (bottom - top + 1) * (right - left + 1);
    }

    /**
     * 🔥 Binary Search on Rows
     * Goal:
     *   - find FIRST row containing '1' (searchFirst = true)
     *   - find LAST row containing '1'  (searchFirst = false)
     *
     * Time: O(log m * n) → checking each row takes O(n)
     */
    private static int searchRows(char[][] image, int low, int high, boolean searchFirst) {

        int answer = -1; // 🔥 Explicit answer tracking (your preferred style)

        while (low <= high) {
            int mid = low + (high - low) / 2;

            // Check if this row contains any '1'
            boolean hasBlack = false;
            for (int col = 0; col < image[0].length; col++) {
                if (image[mid][col] == '1') {
                    hasBlack = true;
                    break;
                }
            }

            if (hasBlack) {
                answer = mid;

                if (searchFirst) {
                    high = mid - 1; // move left
                } else {
                    low = mid + 1;  // move right
                }
            } else {
                if (searchFirst) {
                    low = mid + 1;
                } else {
                    high = mid - 1;
                }
            }
        }

        return answer;
    }

    /**
     * 🔥 Binary Search on Columns
     *
     * Time: O(log n * m)
     */
    private static int searchCols(char[][] image, int low, int high, boolean searchFirst) {

        int answer = -1;

        while (low <= high) {
            int mid = low + (high - low) / 2;

            // Check if this column contains any '1'
            boolean hasBlack = false;
            for (int row = 0; row < image.length; row++) {
                if (image[row][mid] == '1') {
                    hasBlack = true;
                    break;
                }
            }

            if (hasBlack) {
                answer = mid;

                if (searchFirst) {
                    high = mid - 1;
                } else {
                    low = mid + 1;
                }
            } else {
                if (searchFirst) {
                    low = mid + 1;
                } else {
                    high = mid - 1;
                }
            }
        }

        return answer;
    }

    // 🧪 Driver
    public static void main(String[] args) {

        char[][] image = {
            {'0','0','1','0'},
            {'0','1','1','0'},
            {'0','1','0','0'}
        };

        int x = 0, y = 2;

        System.out.println(minArea(image, x, y)); // Output: 6
    }
}
```

# 🧠 How to Think (Interview Strategy)

### Step 1: Constraint Check

> "Less than O(m × n)" → 🚨 brute force not allowed

---

### Step 2: Use Given Pixel (x, y)

> "We already know one black pixel → region is connected"

---

### Step 3: Convert to Boundary Problem

> "Find extreme rows and columns"

---

### Step 4: Spot Monotonicity

> Rows before region → all 0
> Rows inside → contain 1
> Rows after → all 0

👉 Binary Search applies
