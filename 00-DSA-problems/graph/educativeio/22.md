These are **two different graph models for the same problem**. Both are correct, but they optimize around different things.

The key question is:

> **What are we counting?**
>
> We want to minimize the **number of buses taken**, not the number of stops traveled.

---

# 1. First understand the problem as a graph

Suppose:

```text
Route 0: [1, 2, 7]
Route 1: [3, 6, 7]
Route 2: [6, 8, 9]
```

And:

```text
src = 1
dest = 9
```

You can do:

```text
Bus 0: 1 → 2 → 7
                    ↓
                  transfer
                    ↓
Bus 1: 7 → 3 → 6
                    ↓
                  transfer
                    ↓
Bus 2: 6 → 8 → 9
```

So the answer is:

```text
3 buses
```

Notice something important:

We don't care how many stops we travel through.

We care about:

```text
Bus 0 → Bus 1 → Bus 2
```

Therefore, there are two natural ways to model the problem.

---

# Approach 1: BFS on Stops

Your first solution does this:

```text
STOP
 ↓
which buses can I take?
 ↓
all stops reachable by those buses
 ↓
which buses can I take from those stops?
```

So the graph is conceptually:

```text
Stops
  ↓
Buses
  ↓
Stops
  ↓
Buses
```

The important trick is:

> **One BFS level represents taking one bus.**

---

## Example

```text
Route 0 = [1, 2, 7]
Route 1 = [3, 6, 7]
Route 2 = [6, 8, 9]

src = 1
dest = 9
```

Start:

```text
queue = [1]
busesTaken = 0
```

### Level 1

From stop `1`:

```text
stop 1 → Bus 0
```

Take Bus 0:

```text
Bus 0 → {1, 2, 7}
```

We can now reach:

```text
2, 7
```

So:

```text
queue = [2, 7]
busesTaken = 1
```

---

### Level 2

Eventually we process stop `7`.

```text
7 → Bus 1
```

Take Bus 1:

```text
Bus 1 → {3, 6, 7}
```

Now:

```text
queue = [3, 6, ...]
busesTaken = 2
```

---

### Level 3

From stop `6`:

```text
6 → Bus 2
```

Bus 2 contains:

```text
[6, 8, 9]
```

We find destination:

```text
9
```

Therefore:

```text
answer = 3
```

# Why `visitedBuses` is important

This is one of the most important parts of the solution:

```java
if (visitedBuses.contains(bus)) continue;

visitedBuses.add(bus);
```

Suppose:

```text
Bus 0: [1, 2, 7]
Bus 1: [2, 3, 7]
Bus 2: [3, 4]
```

Bus 0 and Bus 1 share multiple stops.

Without `visitedBuses`, we could repeatedly do:

```text
stop → bus → stops → bus → stops
```

and process the same bus many times.

But once we have taken a particular bus, processing that bus again cannot give us anything new.

---

# Why `visitedStops` is also needed

You also have:

```java
if (!visitedStops.contains(nextStop)) {
    visitedStops.add(nextStop);
    queue.offer(nextStop);
}
```

Because many buses can reach the same stop.

For example:

```text
Bus 0 → 7
Bus 1 → 7
Bus 2 → 7
```

We only need to process stop `7` once.

So we have two different kinds of visited state:

```text
visitedStops
visitedBuses
```

They solve two different duplication problems.

# Fully commented version

```java
import java.util.*;

/**
 * Problem:
 * Find the minimum number of buses needed to travel
 * from src to dest.
 *
 * Key idea:
 *
 * We perform BFS starting from the source STOP.
 *
 * But there is an important interpretation:
 *
 *     One BFS level = taking one bus
 *
 * Example:
 *
 *     src
 *      |
 *    Bus 0
 *      |
 *    stops
 *      |
 *    Bus 1
 *      |
 *    stops
 *      |
 *    Bus 2
 *      |
 *    dest
 *
 * Answer = 3 buses
 */
public class BusRoutes {

    public int numBusesToDestination(
            int[][] routes,
            int src,
            int dest) {

        // Already at the destination.
        // We don't need to take any bus.
        if (src == dest) {
            return 0;
        }

        /*
         * ---------------------------------------------------------
         * Step 1: Build:
         *
         *      stop -> buses passing through that stop
         *
         * Example:
         *
         * routes:
         *
         * Bus 0 -> [1, 2, 7]
         * Bus 1 -> [3, 6, 7]
         *
         * Mapping:
         *
         * 1 -> [0]
         * 2 -> [0]
         * 3 -> [1]
         * 6 -> [1]
         * 7 -> [0, 1]
         *
         * This allows us to quickly answer:
         *
         * "I am at stop X. Which buses can I take?"
         * ---------------------------------------------------------
         */
        Map<Integer, List<Integer>> stopToBuses = new HashMap<>();

        for (int bus = 0; bus < routes.length; bus++) {

            for (int stop : routes[bus]) {

                stopToBuses
                        .computeIfAbsent(
                                stop,
                                key -> new ArrayList<>())
                        .add(bus);
            }
        }

        /*
         * ---------------------------------------------------------
         * Step 2: BFS
         *
         * The queue contains stops that we can reach.
         *
         * Important:
         *
         * Each BFS level represents taking ONE additional bus.
         *
         * Level 0:
         *     src
         *
         * Level 1:
         *     stops reachable using 1 bus
         *
         * Level 2:
         *     stops reachable using 2 buses
         *
         * ...
         * ---------------------------------------------------------
         */
        Queue<Integer> queue = new ArrayDeque<>();

        queue.offer(src);

        /*
         * Prevent processing the same stop multiple times.
         */
        Set<Integer> visitedStops = new HashSet<>();

        /*
         * Prevent processing the same bus multiple times.
         */
        Set<Integer> visitedBuses = new HashSet<>();

        visitedStops.add(src);

        int busesTaken = 0;

        while (!queue.isEmpty()) {

            /*
             * Everything currently in the queue belongs
             * to the same BFS level.
             */
            int currentLevelSize = queue.size();

            /*
             * Moving to the next level means:
             *
             * "We are taking one more bus."
             */
            busesTaken++;

            for (int i = 0; i < currentLevelSize; i++) {

                int currentStop = queue.poll();

                /*
                 * Find all buses that pass through
                 * the current stop.
                 */
                List<Integer> busesAtCurrentStop =
                        stopToBuses.getOrDefault(
                                currentStop,
                                Collections.emptyList());

                for (int bus : busesAtCurrentStop) {

                    /*
                     * We have already explored this entire bus.
                     *
                     * Exploring it again cannot produce
                     * any new reachable stops.
                     */
                    if (visitedBuses.contains(bus)) {
                        continue;
                    }

                    visitedBuses.add(bus);

                    /*
                     * Once we take this bus, we can reach
                     * every stop on its route.
                     */
                    for (int nextStop : routes[bus]) {

                        /*
                         * We reached the destination using
                         * the current number of buses.
                         */
                        if (nextStop == dest) {
                            return busesTaken;
                        }

                        /*
                         * Add newly discovered stops to BFS.
                         */
                        if (!visitedStops.contains(nextStop)) {

                            visitedStops.add(nextStop);

                            queue.offer(nextStop);
                        }
                    }
                }
            }
        }

        /*
         * BFS finished without reaching destination.
         *
         * Therefore, there is no possible route.
         */
        return -1;
    }
}
```

# Approach 2: Build a Graph of Buses

Your second solution takes a different perspective.

Instead of:

```text
stop → buses → stops
```

we directly create:

```text
bus → bus → bus
```

Two buses are connected if they share at least one station.

For example:

```text
Bus 0: [1, 2, 7]
Bus 1: [3, 6, 7]
Bus 2: [6, 8, 9]
```

Since:

```text
Bus 0 ∩ Bus 1 = {7}
Bus 1 ∩ Bus 2 = {6}
```

we construct:

```text
Bus 0 -------- Bus 1 -------- Bus 2
```

Now the problem becomes a very simple BFS.

---

# Start and destination buses

Suppose:

```text
src = 1
dest = 9
```

Which buses can we take initially?

```text
src = 1
     ↓
Bus 0
```

So:

```text
startBuses = {0}
```

Which buses can directly take us to destination?

```text
dest = 9
     ↓
Bus 2
```

So:

```text
endBuses = {2}
```

Now BFS:

```text
Bus 0
  ↓
Bus 1
  ↓
Bus 2
```

Therefore:

```text
3 buses
```

# Fully commented graph version

```java
import java.util.*;

/**
 * Problem:
 * Find the minimum number of buses required to travel
 * from src to dest.
 *
 * Approach:
 *
 * Build a graph where:
 *
 *     Each node = one bus
 *
 *     Edge between Bus A and Bus B
 *     = the two buses share at least one stop.
 *
 * Then run BFS on this bus graph.
 *
 * Example:
 *
 * Bus 0 -> [1, 2, 7]
 * Bus 1 -> [3, 6, 7]
 * Bus 2 -> [6, 8, 9]
 *
 * Bus 0 and Bus 1 share stop 7.
 * Bus 1 and Bus 2 share stop 6.
 *
 * Therefore:
 *
 *     Bus 0 -------- Bus 1 -------- Bus 2
 *
 * If src = 1 and dest = 9:
 *
 *     Start with Bus 0
 *     Take Bus 0
 *     Transfer to Bus 1
 *     Transfer to Bus 2
 *
 * Answer = 3
 */
public class BusRoutesGraph {

    public int numBusesToDestination(
            int[][] routes,
            int src,
            int dest) {

        // Already at destination.
        if (src == dest) {
            return 0;
        }

        int numberOfBuses = routes.length;

        /*
         * ---------------------------------------------------------
         * Step 1: Build the BUS graph.
         *
         * graph.get(i) contains all buses that can be reached
         * from bus i by transferring at a common stop.
         *
         * Example:
         *
         * graph:
         *
         * 0 -> [1]
         * 1 -> [0, 2]
         * 2 -> [1]
         * ---------------------------------------------------------
         */
        List<List<Integer>> busGraph = new ArrayList<>();

        for (int bus = 0; bus < numberOfBuses; bus++) {
            busGraph.add(new ArrayList<>());
        }

        /*
         * Compare every pair of buses.
         *
         * If they have at least one common stop,
         * connect them.
         */
        for (int firstBus = 0;
             firstBus < numberOfBuses;
             firstBus++) {

            /*
             * Put all stops of firstBus into a Set.
             *
             * This lets us efficiently ask:
             *
             * "Does firstBus contain this stop?"
             */
            Set<Integer> firstBusStops = new HashSet<>();

            for (int stop : routes[firstBus]) {
                firstBusStops.add(stop);
            }

            /*
             * Only compare with buses after firstBus.
             *
             * This avoids checking the same pair twice.
             *
             * Instead of:
             *
             *     0 -> 1
             *     1 -> 0
             *
             * we process the pair only once.
             */
            for (int secondBus = firstBus + 1;
                 secondBus < numberOfBuses;
                 secondBus++) {

                /*
                 * Check whether the two buses share
                 * at least one stop.
                 */
                boolean busesShareAStop = false;

                for (int stop : routes[secondBus]) {

                    if (firstBusStops.contains(stop)) {
                        busesShareAStop = true;
                        break;
                    }
                }

                /*
                 * If they share a stop, a passenger can
                 * transfer between these buses.
                 */
                if (busesShareAStop) {

                    busGraph.get(firstBus).add(secondBus);
                    busGraph.get(secondBus).add(firstBus);
                }
            }
        }

        /*
         * ---------------------------------------------------------
         * Step 2: Find buses that can be boarded at src.
         *
         * If:
         *
         *     src = 1
         *
         * and:
         *
         *     Bus 0 -> [1, 2, 7]
         *
         * then Bus 0 is a possible starting bus.
         * ---------------------------------------------------------
         */
        Set<Integer> startBuses = new HashSet<>();

        /*
         * Find buses that contain the destination.
         *
         * These are the buses on which we can finish
         * our journey.
         */
        Set<Integer> destinationBuses = new HashSet<>();

        for (int bus = 0; bus < numberOfBuses; bus++) {

            for (int stop : routes[bus]) {

                if (stop == src) {
                    startBuses.add(bus);
                }

                if (stop == dest) {
                    destinationBuses.add(bus);
                }
            }
        }

        /*
         * If no bus contains src, we cannot start the journey.
         */
        if (startBuses.isEmpty()) {
            return -1;
        }

        /*
         * If no bus contains dest, destination cannot be reached.
         */
        if (destinationBuses.isEmpty()) {
            return -1;
        }

        /*
         * ---------------------------------------------------------
         * Step 3: BFS over BUSES.
         *
         * Every BFS node represents a bus.
         *
         * Starting buses require taking 1 bus.
         */
        Queue<Integer> queue = new ArrayDeque<>();

        for (int startingBus : startBuses) {
            queue.offer(startingBus);
        }

        /*
         * A bus only needs to be explored once.
         */
        Set<Integer> visitedBuses = new HashSet<>(startBuses);

        int busesTaken = 1;

        while (!queue.isEmpty()) {

            /*
             * One BFS level represents buses that require
             * the same number of buses from the source.
             */
            int currentLevelSize = queue.size();

            for (int i = 0; i < currentLevelSize; i++) {

                int currentBus = queue.poll();

                /*
                 * If this bus reaches destination,
                 * we have found our answer.
                 */
                if (destinationBuses.contains(currentBus)) {
                    return busesTaken;
                }

                /*
                 * Try transferring to every bus that
                 * shares a stop with currentBus.
                 */
                for (int nextBus : busGraph.get(currentBus)) {

                    if (visitedBuses.contains(nextBus)) {
                        continue;
                    }

                    visitedBuses.add(nextBus);
                    queue.offer(nextBus);
                }
            }

            /*
             * Moving to the next BFS level means
             * taking one additional bus.
             */
            busesTaken++;
        }

        /*
         * No bus sequence connects src to dest.
         */
        return -1;
    }
}
```

# The important difference

The two approaches are essentially representing the same underlying problem differently.

### Approach 1

```text
                Bus 0
               / |  \
              /  |   \
           Stop Stop Stop
                    |
                   Bus 1
```

Graph nodes:

```text
STOPS
```

We use a separate mapping:

```text
stop → buses
```

---

### Approach 2

```text
Bus 0 -------- Bus 1 -------- Bus 2
```

Graph nodes:

```text
BUSES
```

An edge means:

```text
these two buses share a stop
```

---

# Complexity comparison

Let:

```text
B = number of buses
S = total number of stops across all routes
```

Given the constraints:

```text
B <= 50
route length <= 100
```

so:

```text
S <= 5000
```

### Approach 1 — Stop BFS

Building:

```text
stop → buses
```

takes:

```text
O(S)
```

BFS processes each bus at most once and its stops when the bus is explored:

```text
O(S)
```

So approximately:

```text
Time:  O(S)
Space: O(S)
```

This is particularly nice because we don't explicitly construct all bus-to-bus edges.

---

### Approach 2 — Bus graph

We potentially compare every pair of buses:

```text
B²
```

For each pair, we inspect their stops.

Worst case:

```text
O(B² × L)
```

where `L` is route length.

With the constraints:

```text
B <= 50
L <= 100
```

this is completely manageable.

Space:

```text
O(B² + S)
```

because we store the bus graph plus the routes.

---

# Which mental model should you remember?

I would remember **both**, because they teach an important graph-design technique.

### Model 1: "Where can I go from this stop?"

```text
STOP
  ↓
BUSES
  ↓
STOPS
```

This is usually the more natural implementation for this problem.

### Model 2: "Which buses can I transfer between?"

```text
BUS
 ↓
BUS
 ↓
BUS
```

This makes the optimization target extremely obvious:

```text
BFS distance = number of buses
```

## One subtle but very important insight

This problem is a great example of **choosing the right graph representation**.

You could naïvely create:

```text
Stop 1 → Stop 2
Stop 2 → Stop 7
Stop 7 → Stop 3
...
```

and run BFS.

But that would optimize:

```text
number of stops traveled
```

not:

```text
number of buses taken
```

For example:

```text
Bus A:
1 → 2 → 3 → 4 → 5 → 6 → 7 → 8

Bus B:
1 → 100
```

If destination is `8`, the correct answer is:

```text
1 bus
```

even though we visit many stops.

So the graph should make **"taking a bus" the unit of BFS distance**.

That's the core insight behind both of your solutions.
