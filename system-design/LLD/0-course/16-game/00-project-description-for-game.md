# Project Description for Game

## Introduction

Online games are wildly popular and played by people of all ages, across every device — phones, computers, tablets, you name it. There are many different flavors of them too: board games, arcade games, role-playing games, first-person shooters, fantasy games. The scenario and problems in this chapter live in that world — game development.

## Statement

You work for a company that builds online games. Your team is developing a variety of board and arcade games, including traditional card games like poker as well as a few custom card games. Every one of these games can be played in single-player mode, so your team also needs to build a computer player that can play against a human.

Your first task is a feature that helps the computer player play a variation of poker — figuring out whether a given hand of cards is a *hand of straights*.

For the next feature, you'll build a custom card game called **Fizzle**. Here, the computer player has to find the maximum number of points it can score by picking cards from one end or the other of a row of ten revealed cards.

Finally, you'll work on **Balloon Splash**, one of the arcade games in development. The player splashes adjacent balloons of the same color; each splash earns points, and the splashed balloons disappear.

## Features

To implement the functionality above, we need the following features:

- **Feature #1:** Determine whether a hand of straights is possible.
- **Feature #2:** Find the maximum points that can be obtained from a set of ten random cards.
- **Feature #3:** Repeatedly remove a given number of adjacent, same-colored balloons until no more can be splashed.

In the coming lessons, we'll build out these features one by one — and, as always, tie each solution back to the classic interview problem it's really testing.
