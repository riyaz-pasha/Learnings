# What Did We Learn?

The problems we solved to build out the Stocks platform's features are, underneath the trading-floor dressing, some of the most frequently asked interview questions at top-tier companies. Now that we've built them once as real features, we can recognize the same patterns wherever they show up next.

| Feature | Real interview pattern |
|---|---|
| Feature #1: Validate Price | Valid Number (state-machine string validation) |
| Feature #2: Settling Period | Task Scheduler (greedy scheduling with a cooldown) |
| Feature #3: Goals Fulfilled | Split Array into Consecutive Subsequences (greedy grouping) |
| Feature #4: Milestone Reached | Search a 2D Matrix (binary search over a virtual flattened array) |
| Feature #5: Top Brokers | Top K Frequent Elements (frequency map + bounded min-heap) |
| Feature #6: Assign Transactions | Reverse Nodes in k-Group (in-place linked-list reversal) |
| Feature #7: Process Transactions | String to Integer (atoi) (careful left-to-right parsing with overflow handling) |
| Feature #8: Find Intervals | Daily Temperatures (monotonic stack) |
